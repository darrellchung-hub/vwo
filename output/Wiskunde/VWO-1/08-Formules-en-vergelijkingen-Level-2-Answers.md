# Antwoordmodel — Hoofdstuk 8 — Niveau 2

*Answer Key — Chapter 8 — Level 2*

*Antwoorden bij [de vragen](08-Formules-en-vergelijkingen-Level-2.md).*

Answers for [the questions](08-Formules-en-vergelijkingen-Level-2.md).

1. *5x - 2x = 3x en 4 - 1 = 3, dus 3x + 3.*

   5x - 2x = 3x and 4 - 1 = 3, so 3x + 3.

2. *4a + 3 = 27; 4a = 24; a = 6. Controle: 4 x 6 + 3 = 27.*

   4a + 3 = 27; 4a = 24; a = 6. Check: 4 x 6 + 3 = 27.

3. *5x - 7 = 18; 5x = 25; x = 5.*

   5x - 7 = 18; 5x = 25; x = 5.

4. *Trek 2x van beide kanten af: 5 = x + 1. Trek 1 af: x = 4.*

   Subtract 2x from both sides: 5 = x + 1. Subtract 1: x = 4.

5. *Na 4 aftrekken blijft 3x = 15 over. Deel daarna door 3: x = 5.*

   After subtracting 4, 3x = 15 remains. Then divide by 3: x = 5.

6. *19 = 7 + 2d; 12 = 2d; d = 6.*

   19 = 7 + 2d; 12 = 2d; d = 6.

7. *Omtrek: 2x + 2(x + 3) = 22. Dus 4x + 6 = 22, 4x = 16 en x = 4 cm. De lengte is x + 3 = 7 cm.*

   Perimeter: 2x + 2(x + 3) = 22. So 4x + 6 = 22, 4x = 16, and x = 4 cm. The length is x + 3 = 7 cm.

8. *Deel beide kanten door 4: x - 1 = 5. Dus x = 6.*

   Divide both sides by 4: x - 1 = 5. Therefore x = 6.

9. *Trek 2x af: x + 6 = 14. Trek 6 af: x = 8.*

   Subtract 2x: x + 6 = 14. Subtract 6: x = 8.

10. *De gelijkheid blijft waar als je aan beide kanten dezelfde bewerking uitvoert. Trek bij 2x + 4 = 10 aan beide kanten 4 af: 2x = 6; deel daarna beide kanten door 2: x = 3.*

   The equality stays true if you perform the same operation on both sides. For 2x + 4 = 10, subtract 4 from both sides: 2x = 6; then divide both sides by 2: x = 3.
