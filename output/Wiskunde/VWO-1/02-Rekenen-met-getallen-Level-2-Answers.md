# Antwoordmodel — Hoofdstuk 2 — Niveau 2

*Answer Key — Chapter 2 — Level 2*

*Antwoorden bij [de vragen](02-Rekenen-met-getallen-Level-2.md).*

Answers for [the questions](02-Rekenen-met-getallen-Level-2.md).

1. *5/6 - 1/4 = 10/12 - 3/12 = 7/12.*

   5/6 - 1/4 = 10/12 - 3/12 = 7/12.

2. *3/4 + 2/3 = 9/12 + 8/12 = 17/12 = 1 5/12.*

   3/4 + 2/3 = 9/12 + 8/12 = 17/12 = 1 5/12.

3. *2/5 x 15/4 = 30/20 = 3/2 = 1 1/2.*

   2/5 x 15/4 = 30/20 = 3/2 = 1 1/2.

4. *3,6 / 0,6 = 36 / 6 = 6.*

   3.6 / 0.6 = 36 / 6 = 6.

5. *15% van 240 = 0,15 x 240 = 36.*

   15% of 240 = 0.15 x 240 = 36.

6. *30% van €150 is €45. Nieuwe prijs: €150 - €45 = €105.*

   30% of €150 is €45. New price: €150 - €45 = €105.

7. *0,375 = 375/1000 = 3/8.*

   0.375 = 375/1000 = 3/8.

8. *7/10 = 0,70. Dat is 0,02 groter dan 0,68.*

   7/10 = 0.70. It is 0.02 greater than 0.68.

9. *10 porties is 10/4 = 2,5 keer zoveel. 2/3 x 2,5 = 5/3 = 1 2/3 kop bloem.*

   10 servings is 10/4 = 2.5 times as much. 2/3 x 2.5 = 5/3 = 1 2/3 cups of flour.

10. *Bij optellen moeten de breuken eerst dezelfde noemer hebben; je telt niet de noemers op. 2/3 = 4/6, dus 2/3 + 1/6 = 4/6 + 1/6 = 5/6.*

   When adding fractions, first use a common denominator; do not add the denominators. 2/3 = 4/6, so 2/3 + 1/6 = 4/6 + 1/6 = 5/6.
