# Antwoordmodel — Hoofdstuk 11 — Niveau 2

*Answer Key — Chapter 11 — Level 2*

*Antwoorden bij [de vragen](11-Kijk-op-kans-Level-2.md).*

Answers for [the questions](11-Kijk-op-kans-Level-2.md).

1. *1/2 x 1/2 = 1/4.*

   1/2 x 1/2 = 1/4.

2. *Kans op kop is 1/2; kans op even is 3/6 = 1/2. Samen: 1/2 x 1/2 = 1/4.*

   Probability of heads is 1/2; probability of an even number is 3/6 = 1/2. Together: 1/2 x 1/2 = 1/4.

3. *4/7 x 3/6 = 12/42 = 2/7.*

   4/7 x 3/6 = 12/42 = 2/7.

4. *2/5 x 3/4 = 6/20 = 3/10.*

   2/5 x 3/4 = 6/20 = 3/10.

5. *Kop-kop, kop-munt, munt-kop en munt-munt.*

   Heads-heads, heads-tails, tails-heads, and tails-tails.

6. *3 x 4 = 12 combinaties.*

   3 x 4 = 12 combinations.

7. *2/7 x 1/6 = 2/42 = 1/21.*

   2/7 x 1/6 = 2/42 = 1/21.

8. *De uitkomsten zijn kop-kop, kop-munt, munt-kop en munt-munt. Drie van de vier hebben minstens één keer kop, dus 3/4.*

   The outcomes are heads-heads, heads-tails, tails-heads, and tails-tails. Three of the four have at least one head, so the probability is 3/4.

9. *3/5 x 2/4 = 6/20 = 3/10.*

   3/5 x 2/4 = 6/20 = 3/10.

10. *Met terugleggen: 3/5 x 3/5 = 9/25. Zonder terugleggen: 3/5 x 2/4 = 3/10. 9/25 = 0,36 en 3/10 = 0,3, dus met terugleggen is de kans groter.*

   With replacement: 3/5 x 3/5 = 9/25. Without replacement: 3/5 x 2/4 = 3/10. 9/25 = 0.36 and 3/10 = 0.3, so the probability is greater with replacement.
