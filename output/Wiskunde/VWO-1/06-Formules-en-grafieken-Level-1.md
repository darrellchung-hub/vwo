# Hoofdstuk 6 — Formules en grafieken — Niveau 1

*Chapter 6 — Formulas and Graphs — Level 1*

*Basisvragen over beschrijvingen, invullen, tabellen en lineaire formules.*

Foundation questions on descriptions, substitution, tables, and linear formulas.

*Originele oefenvragen op basis van het lesbestand. Antwoorden: [antwoordmodel](06-Formules-en-grafieken-Level-1-Answers.md).*

Original practice questions based on the lesson file. Answers: [answer key](06-Formules-en-grafieken-Level-1-Answers.md).

1. *Een spel kost €5 startgeld en €2 per rit. Schrijf een formule voor de totale kosten C bij r ritten.*

   A game costs €5 to start and €2 per ride. Write a formula for the total cost C for r rides.

2. *Bereken y = 4x als x = 2.*

   Calculate y = 4x when x = 2.

3. *Bereken y = 2x + 1 als x = 3.*

   Calculate y = 2x + 1 when x = 3.

4. *Vul voor y = 3x + 2 een tabel in bij x = 0, 1 en 2.*

   Complete a table for y = 3x + 2 when x = 0, 1, and 2.

5. *Je leest 7 bladzijden per dag. Schrijf een formule voor het aantal bladzijden p na d dagen.*

   You read 7 pages each day. Write a formula for the number of pages p after d days.

6. *Een taxi rekent €8 instaptarief en €3 per kilometer. Schrijf een formule voor de prijs P bij k kilometer.*

   A taxi charges an €8 starting fee and €3 per kilometre. Write a formula for the price P for k kilometres.

7. *In een tabel hoort bij x = 0, 1 en 2 de waarde y = 4, 7 en 10. Welke y-waarde hoort bij x = 3 als het patroon doorgaat?*

   In a table, x = 0, 1, and 2 correspond to y = 4, 7, and 10. What y-value corresponds to x = 3 if the pattern continues?

8. *Maak een tabel voor y = 5x bij x = 0, 1, 2 en 3.*

   Make a table for y = 5x when x = 0, 1, 2, and 3.

9. *Is de grafiek van y = 3x + 1 een rechte lijn?*

   Is the graph of y = 3x + 1 a straight line?

10. *Bereken y = x + 4 als x = 3.*

   Calculate y = x + 4 when x = 3.
