# Antwoordmodel — Hoofdstuk 6 — Niveau 1

*Answer Key — Chapter 6 — Level 1*

*Antwoorden bij [de vragen](06-Formules-en-grafieken-Level-1.md).*

Answers for [the questions](06-Formules-en-grafieken-Level-1.md).

1. *C = 5 + 2r.*

   C = 5 + 2r.

2. *y = 4 x 2 = 8.*

   y = 4 x 2 = 8.

3. *y = 2 x 3 + 1 = 7.*

   y = 2 x 3 + 1 = 7.

4. *Bij x = 0, 1, 2 hoort y = 2, 5, 8.*

   For x = 0, 1, 2, the y-values are 2, 5, 8.

5. *p = 7d.*

   p = 7d.

6. *P = 8 + 3k.*

   P = 8 + 3k.

7. *De y-waarde neemt steeds met 3 toe. Bij x = 3 is y = 13.*

   The y-value increases by 3 each time. When x = 3, y = 13.

8. *Bij x = 0, 1, 2, 3 hoort y = 0, 5, 10, 15.*

   For x = 0, 1, 2, 3, the y-values are 0, 5, 10, 15.

9. *Ja. Een formule van de vorm y = ax + b heeft een rechte lijn als grafiek.*

   Yes. A formula of the form y = ax + b has a straight-line graph.

10. *y = 3 + 4 = 7.*

   y = 3 + 4 = 7.
