# Antwoordmodel — Hoofdstuk 10 — Niveau 2

*Answer Key — Chapter 10 — Level 2*

*Antwoorden bij [de vragen](10-Rekenen-met-variabelen-Level-2.md).*

Answers for [the questions](10-Rekenen-met-variabelen-Level-2.md).

1. *4x + 3x = 7x en -2 + 5 = 3, dus 7x + 3.*

   4x + 3x = 7x and -2 + 5 = 3, so 7x + 3.

2. *3 x 4 x a x a = 12a².*

   3 x 4 x a x a = 12a².

3. *2 x 6 + 3 = 15.*

   2 x 6 + 3 = 15.

4. *x² = 4² = 16. Dus y = 3 x 16 - 2 = 46.*

   x² = 4² = 16. Therefore y = 3 x 16 - 2 = 46.

5. *x² = 16 en 3x = 12. x² is 4 groter.*

   x² = 16 and 3x = 12. x² is 4 greater.

6. *2^5 + 3² = 32 + 9 = 41.*

   2^5 + 3² = 32 + 9 = 41.

7. *P = 4 x 7 = 28 cm.*

   P = 4 x 7 = 28 cm.

8. *Bij s = 2 is A = 4; bij s = 3 is A = 9; bij s = 5 is A = 25.*

   When s = 2, A = 4; when s = 3, A = 9; when s = 5, A = 25.

9. *5x² - 3x² = 2x² en 2x + x = 3x, dus 2x² + 3x.*

   5x² - 3x² = 2x² and 2x + x = 3x, so 2x² + 3x.

10. *x en x² zijn niet gelijksoortig: x is de eerste macht en x² is de tweede macht. Je kunt ze dus niet tot één term samenvoegen.*

   x and x² are not like terms: x is to the first power and x² is to the second power. They cannot be combined into one term.
